Features

📦 SBOM Generation

Generate SBOMs in standard formats (SPDX, CycloneDX) from source trees and container images.

🔍 Vulnerability Analysis

Match every component against known CVE databases and get a clear, prioritized risk report.

📜 License Compliance

See every license in your dependency tree and catch incompatible or risky licenses early.

🗄️ Central Inventory

Keep all your SBOMs in one searchable place — know instantly which projects use an affected package.

🐳 One-Command Deploy

Ships as a single Docker image. No accounts, no cloud lock-in — run it anywhere Docker runs.

🆓 Free Forever

SBOM Shield is free to use. Pull it from Docker Hub and own your software supply-chain data.

Quick Start

  1. 1. Pull the image

    docker pull YOUR_DOCKERHUB_USER/sbom-shield:latest

  2. 2. Run the platform

    docker run -d \
  --name sbom-shield \
  -p 8080:8080 \
  -v sbom-shield-data:/data \
  YOUR_DOCKERHUB_USER/sbom-shield:latest

  3. 3. Open the dashboard

    Visit http://localhost:8080 and scan your first project or image.

How It Works

1 — Scan

Point SBOM Shield at a repository, directory, or container image. It inventories every component and dependency.

2 — Analyze

Components are cross-referenced with vulnerability and license databases to build a complete risk picture.

3 — Act

Export standards-compliant SBOMs, review prioritized findings, and track your remediation over time.

FAQ

Is SBOM Shield really free?

Yes. The platform is free to pull from Docker Hub and run on your own infrastructure.

What SBOM formats are supported?

Standard formats such as SPDX and CycloneDX, so your SBOMs work with the rest of your toolchain.

Where does my data go?

Nowhere. SBOM Shield is self-hosted — all scans and SBOMs stay on your own machine or server.

What do I need to run it?

Just Docker (or any OCI-compatible runtime). One docker run command and you're up.
